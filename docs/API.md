# API Reference

Base path: `/api` (see `backend/app/config.py: api_prefix`).
Interactive docs are auto-generated by FastAPI at `/docs` when the server is
running.

## Subjects & topics

| Method | Path                              | Description                     |
|--------|------------------------------------|----------------------------------|
| GET    | `/subjects`                        | List all subjects               |
| POST   | `/subjects`                        | Create a subject                |
| GET    | `/subjects/{subject_id}/topics`    | List topics for a subject       |
| POST   | `/subjects/{subject_id}/topics`    | Create a topic under a subject  |

## Notes

| Method | Path                | Description                          |
|--------|----------------------|----------------------------------------|
| GET    | `/notes?topic_id=`   | List notes, optionally by topic       |
| POST   | `/notes`              | Create a note (title, content, cues)  |
| PATCH  | `/notes/{note_id}`    | Update a note                         |

## Questions

| Method | Path                      | Description                              |
|--------|----------------------------|--------------------------------------------|
| GET    | `/questions?topic_id=`     | List questions, optionally by topic       |
| POST   | `/questions`                | Create a question                        |
| GET    | `/questions/due`            | Questions due for review right now       |
| GET    | `/questions/{question_id}`  | Fetch a single question                  |

## Reviews (retrieval practice)

| Method | Path              | Description                                                    |
|--------|--------------------|-------------------------------------------------------------------|
| GET    | `/reviews/today`   | Reviews submitted today                                          |
| POST   | `/reviews`          | Submit a rating for a question; reschedules `next_review` via the spaced-repetition scheduler |

Rating values: `again`, `hard`, `good`, `easy` (see
`backend/app/services/scheduler.py` for how each maps to an interval).

## Feynman self-explanation

| Method | Path                    | Description                                             |
|--------|--------------------------|--------------------------------------------------------------|
| GET    | `/feynman/{topic_id}`    | Past explanations for a topic                                |
| POST   | `/feynman`                | Submit an explanation + optional checklist; returns a coverage self-check |

## Study sessions

| Method | Path                            | Description                          |
|--------|-----------------------------------|-----------------------------------------|
| POST   | `/sessions`                       | Start a session                        |
| PATCH  | `/sessions/{session_id}/finish`   | Finish a session with stats            |

## Dashboard

| Method | Path         | Description                                                        |
|--------|---------------|--------------------------------------------------------------------|
| GET    | `/dashboard`  | Aggregated payload: due counts, retention by topic, weakest topics, today's totals |

See `frontend/lib/types.ts` for the exact response shapes as consumed by the
frontend, and `backend/app/schemas/*.py` for the source-of-truth Pydantic
models.
